# Applied Math Method Map
Static Astro + Tailwind site, deployed to Cloudflare Pages.
Audience: high school students starting research projects.
Content lives in src/content/ as Markdown with frontmatter, validated by Zod schemas.
- Never invent paper citations. Use only papers listed in the content files.
- Keep the site fully static (no backend).
- Run `npm run build` before declaring any task done.
- Mobile-first; the grid must be usable on a phone.
